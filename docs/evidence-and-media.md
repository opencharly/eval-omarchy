# Evidence and media

- Status: **active** — the evidence/artifact contract for every evaluation.
- Owner: the omarchy eval lane (`eval-lane-plan` in charly.yml).
- Source of truth: the lane contract — the `omarchy-eval-media` skill entity in
  `candy/eval-lane/charly.yml`.

## What lives where

| Path | Content | Committed? |
|---|---|---|
| `.check/<bed>/<calver>/summary.yml` + per-step logs | check-run artifacts per test environment + run date | **gitignored** (regenerated by every run) |
| `media/<calver>/<bed>/` | recordings: asciinema `.cast`/`.gif` + SPICE `.mjpeg`/`.mp4`/`.png` | **gitignored** (large) |
| `eval/pr-<N>.md` | the evaluation report (rendered from the inline `eval-lane-plan` template) | committed |
| `pr-beds/pr-<N>/charly.yml` `pr-beds/pr-<N>-control/charly.yml` | the per-PR eval + control beds | committed |
| `metrics/<calver>-pr-<N>.md`, `stage-findings.yml` | the per-run lane metrics + ledger dump | committed |
| `setup-defects/<calver>-pr-<N>.md` | the improvement ledger (harness-failure records) | committed |

## The three-artifact media contract (mandatory)

Every evaluation produces a terminal asciinema `.cast` AND a full-screen SPICE video
(MJPEG → MP4) AND a screenshot (PNG) — plus the `.gif` derived from the `.cast`. The
evidence-audit stage (`media_gate`) asserts every artifact is present and above its
minimum size. The binding detail lives in the `omarchy-eval-media` skill entity.

## Retention

- Small, diffable evidence (metrics, stage-findings, the report) is committed.
- Heavy recording media stays gitignored in `media/`; a `.cast` is small enough to
  commit only when a change explicitly needs it as change-proof (then prune after merge
  once the durable record exists — git history retains the bytes).
- `.check/` artifacts are never committed: they are regenerated by `charly check run`,
  and the same calver run re-creates them from the committed beds.

## Update triggers

- A change to the recording/evidence steps in the oracle template → update the
  `omarchy-eval-media` skill entity and this page together.
- A change to what is committed (e.g. a new artifact type) → this page.
