# Evidence and media

- Status: **active** — the evidence/artifact contract for every evaluation.
- Owner: the omarchy eval lane (opencharly/opencharly .pi/agents/omarchy-eval-runner.md).
- Source of truth: the lane contract — eval/PR-EVAL-LANE.md + eval/references/*.md (media-contract.md).

## What lives where

| Path | Content | Committed? |
|---|---|---|
| `.check/<bed>/<calver>/summary.yml` + per-step logs | check-run artifacts per test environment + run date | **gitignored** (regenerated by every run) |
| `media/<pr>-<calver>/` | recordings: asciinema `.cast` + full-screen video per pr+run-date | **gitignored** |
| `eval/evidence/` | small committed evidence: summary.yml + per-check logs per pr+run-date; batch matrices; verdict.yml; rendered-comment.md | committed |
| `eval/pr-<N>.md` | the evaluation report (rendered from eval/PR-EVAL-TEMPLATE.md) | committed |

## The three-artifact media contract (mandatory)

Every evaluation produces a terminal asciinema `.cast` AND a full-screen video (desktop
or VM-display recording) AND the check output surfaced on the desktop and visible in the
recording frames. The binding detail lives in eval/references/media-contract.md.

## Retention

- Small, diffable evidence (summary.yml, verdict.yml, matrices, stats) is committed in
eval/evidence/.
- Heavy recording media stays gitignored in `media/`; a `.cast` is small enough to
commit only when a change explicitly needs it as change-proof (then prune after merge
once the durable record exists — git history retains the bytes).
- `.check/` artifacts are never committed: they are regenerated by `charly check run`,
and the same calver run re-creates them from the committed beds.

## Update triggers

- A change to the recording/evidence steps in the oracle template → update
eval/references/media-contract.md and this page together.
- A change to what eval/evidence/ commits (e.g. a new artifact type) → this page.
