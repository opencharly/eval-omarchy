## Summary of changes

Add the canonical **PR-eval template** to eval-omarchy so every omarchy PR evaluation is rendered from one file carrying the mandatory **EXTERNAL, NON-AUTHORITATIVE-by-opencharly.ai** disclaimer — for the report (`eval/pr-<N>.md`) and the operator-approved PR comment alike.

- `README.md`: external/non-authoritative statement at the top; layout table gains the template row; Eval results section now requires template-conform reports with the disclaimer verbatim.
- `charly.yml`: header comment synced (template route + disclaimer).
