# 2026.246.2054 — feat(rollup): fold the golden sha256 into the cache key (stale-verdict invalidation)

## Summary

Fold the golden snapshot's sha256 into the omarchy-rollup cache key (plan/omarchy-pr-validation-disk-link-gif.md, Phase 2).

The rollup's SHA-keyed skip logic previously keyed on (bed, calver) — a golden-base re-provision did not invalidate cached verdicts, so a verdict against an OLD base could be reported as CACHED. This change adds a `--golden-sha256` sidecar (a JSON map of channel → golden snapshot sha256, written by the golden-base provisioning) and folds the golden identity into the cache key: a re-provisioned golden invalidates every cached verdict against the old base (they went STALE). A `--self-test` mode proves the invalidation behavior.

## How tested — the changed path executed live

**The invalidation behavior, run against the real .check tree:**

```
$ echo '{"check-omarchy-pr-vm-anchored": "golden-A-sha256"}' > /tmp/golden-A.json
$ echo '{"check-omarchy-pr-vm-anchored": "golden-B-sha256"}' > /tmp/golden-B.json
$ python3 scripts/omarchy-rollup.py <check-root> --cache /tmp/cache-A.json --golden-sha256 /tmp/golden-A.json   # run 1: populates the cache
$ python3 scripts/omarchy-rollup.py <check-root> --cache /tmp/cache-A.json --golden-sha256 /tmp/golden-A.json   # run 2: same golden → CACHED
check-omarchy-pr-vm-anchored  2026.246.1809  FAIL  7  True   vm-create
$ python3 scripts/omarchy-rollup.py <check-root> --cache /tmp/cache-A.json --golden-sha256 /tmp/golden-B.json   # run 3: re-provisioned golden → INVALIDATED
check-omarchy-pr-vm-anchored  2026.246.1809  FAIL  7  False  vm-create
```

The same bed+calver is `cached: True` with golden A and `cached: False` with golden B — the golden folding invalidates stale verdicts.

**The self-test (B12):**

```
$ python3 scripts/omarchy-rollup.py --self-test
test_invalidation: PASS (golden folding invalidates cached verdicts)
```

The test asserts: same golden → same key; re-provisioned golden → different key (invalidation); a bed with no golden entry is unaffected.
