# 2026.257.0900 — fix(eval-lane): correct media_gate min.mp4 bound and cold-read suggestions type

## Summary

Two eval-lane config defects the eval batch exposed, both root-caused and now proven live:

**1. `media_gate` `min.mp4` was `4096` — inside the legitimate range of a short clip.** A short, mostly-static desktop clip transcodes to a small H.264 mp4 (the previously-flagged runs came in at 4064 / 4047 B, while the passing one was 5877 B). The `4096` floor flagged valid recordings as "too small", failing `evidence-audit`, which cascaded into the `ledger-gate` FAIL and a blank metric. Lowered to `512` (still rejects an empty/broken artefact) in BOTH the plan-level `media.min` and the `evidence-audit` `media_gate` input.

**2. The cold-read `suggestions` output was declared `type: string`, but the model returns a LIST** — `"suggestions": expected a string, got []interface {}` crashed the cold-read stage. The contract is now `string_list` (which `scalar()` renders space-joined for the report), and the prompt names the type explicitly.
