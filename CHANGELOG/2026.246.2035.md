# 2026.246.2035 — feat(candy): omarchy-eval-record — recording tooling (tmux + asciinema) for eval venues

## Summary

Add `candy/omarchy-eval-record` — the recording tooling package for omarchy PR evaluations (eval rule 7 candidate, plan/omarchy-pr-validation-disk-link-gif.md Phase 3).

The candy installs tmux + asciinema natively (pacman) so a venue can run the record: gif loop (start a terminal recording → run a command → stop → render the .cast to an animated GIF with agg). agg itself is NOT packaged in any distro — it arrives via the asciinema layer's pinned prebuilt binary (layer-asciinema v2026.246.1622, which also ships the DejaVu monospace font). Add this candy to a bed whose venue derives from omarchy-vm (which does not carry the recording tools by default); the omarchy-suite-base already composes layer-tmux + layer-asciinema.
